# T26 — Rust agent: /api/graph + /api/history + /api/power + /api/analytics + /api/battery + /api/thermal

## Goal

Migrate the remaining 6 endpoints to the Rust agent. The Python server stays as fallback.

## Endpoints

### GET /api/graph?metric=X&from=Y&to=Z
Returns a graph payload: array of {ts, value} or rollup buckets. Read from collector JSONL.
Similar to /api/series but with graph-specific formatting (may include gap markers).

### GET /api/history?metric=X&range=Y
Returns historical data for a metric over a named range (1h, 6h, 24h, 7d, 30d).
Read from collector JSONL, down-sample to max 500 points.

### GET /api/power
Returns power data: package_w, cpu_w, gpu_w, ane_w, thermal_pressure, per-cluster freq/residency.
Read from root sample.json (power daemon).

### GET /api/analytics
Returns analytics summary: CPU avg/max, memory avg/max, network totals, disk totals over 24h.
Read from collector JSONL.

### GET /api/battery
Returns battery data: charge_pct, health_pct, cycles, draw_w, time_remaining_min, degradation outlook.
Read from root sample.json + collector history.

### GET /api/thermal
Returns all SMC temps: cpu die, gpu, ssd, battery, plus thermal pressure.
Read from root sample.json.
