# T3 — REA behavioural study of iStat Menus (research only, zero code reuse)

## Goal
Produce `docs/parity.md`'s evidence base: exactly which **operating-system interfaces** a mature monitor uses, so our implementation reads the same sources instead of guessing. This is interoperability research on a licensed copy we own.

## Hard limits — read before you touch anything
- **Do not decompile, disassemble or patch** `iStat Menus.app`. No Hopper, no Ghidra, no `otool -tV`, no dylib extraction.
- **Do not copy** code, assets, icons, nibs, strings or UI layout. We build our own.
- Allowed and expected: `ls`/`bundle` anatomy, `Info.plist` facts, `codesign -d --entitlements`, `nm -u` on *system* frameworks, `lsof`/`fs_usage` on a running iStat, `ioreg` key discovery, `log stream` while opening panels, `sample <pid> 1` for stack shape only (no source reconstruction), and reading Apple's public headers for the APIs observed.
- Work against a **copy** of the app if you need to move it; never modify the installed one.

## Deliverable 1 — `docs/ista-probe.md`
For each panel (CPU, memory, disk, network, GPU, sensors, battery), a row: *panel → observed API/framework → observed key/field → sampling interval (measured) → our equivalent (libproc / sysctl / ioreg / IOReport / SMC) → status*.
Every row must cite the command that produced it. Measured intervals only — not guessed.
Sensors: list the SMC/IOHID keys actually read (e.g. `TC0P`, `Tp0P`, `F0Ac`) as *hypotheses with evidence*, and mark which ones we can read without root.

## Deliverable 2 — `scripts/ista_probe.sh`
One command that reproduces every measurement in the doc, idempotent, read-only, no `sudo` required (skip any step that would need it and print `SKIP: needs root`).

## Deliverable 3 — one paragraph in `docs/parity.md`
"What iStat knows that we do not yet", listing the gaps with the API each requires — this feeds T5's parity table.

## Acceptance commands (all must exit 0)
```
test -f docs/ista-probe.md && grep -c '|' docs/ista-probe.md
test -f scripts/ista_probe.sh && bash -n scripts/ista_probe.sh && echo SH_SYNTAX_OK
bash scripts/ista_probe.sh 2>&1 | tail -20
codesign -d --entitlements - "/Applications/iStat Menus.app" 2>&1 | head -5
ls "/Applications/iStat Menus.app/Contents/MacOS" | head -5
grep -c "SMC\|IOReport\|IOHID\|libproc" docs/ista-probe.md
git status --short | grep -i "app/\|\.png\|\.icns" | head -3; echo "NO_ASSETS_STAGED=$?"
```
