# T21 — Focus-mode tiles + dynamic expansion + customization

## Interaction model (Kishan's spec)

1. **Tiles are dynamic, not static bars.** No more bars filling left-to-right.
   Each tile is a contained box with a number, sparkline, and delta.
2. **Click a tile → it pops up.** The clicked tile expands to ~2x its size
   (inline, not a drawer). Other tiles dim (opacity 0.3) and shift to make room.
   Click again or click another tile → collapse back to the grid.
3. **Expanded tile content:** graph timeline (horizontally scrollable) + stats
   to the side. For CPU: chart + per-core list. For GPU: chart + renderer/VRAM.
   For Network: chart + per-interface. For Battery: chart + health/cycles.
4. **Temperature tile is special:** one tile shows ALL temps (CPU die, GPU, SSD,
   battery) as a compact list + a combined sparkline. Clicking it highlights
   the tile and dims the rest (focus mode). No expansion — just focus.
5. **Click-to-focus toggle:** click a tile → focus (dims others). Click again
   or click another → unfocus (all tiles normal). Escape also unfocuses.
6. **Customizable from anywhere:** a "customize" toggle (in ⚙ settings or a
   floating button) lets the user:
   - Show/hide tiles
   - Reorder tiles (drag-to-reorder within the grid)
   - Pick which metrics appear on each tile
   - Settings persist in localStorage
   - Reset to default button

## Layout

- L1 grid: 3 columns × 2 rows (6 tiles) on desktop, 2 columns on tablet,
  1 column on mobile. Tiles: CPU, Memory, GPU, Battery, Network, Disk,
  Package Power, Thermal. (8 tiles, 3-col = 3 rows)
- Each tile: 120 px min-height, number (24 px) + sparkline (40 px) + delta (10 px).
- Expanded tile: spans 2 columns, 2 rows. Other tiles reflow around it.
- Focus mode (dim others): `is-focused` class on the clicked tile, `is-dimmed`
  on all others. CSS: dimmed opacity 0.35, transition 150 ms.

## Technical

- Use CSS Grid with `grid-template-columns: repeat(3, 1fr)`.
- Expanded tile: `grid-column: span 2; grid-row: span 2;`.
- Dimmed: `opacity: 0.35; pointer-events: none;` (clicking a dimmed tile
  unfocuses instead of focusing).
- Customization stored in `localStorage` key `syswatch-tile-config`.
- Default config: all 8 tiles visible, default order.
- Drag-to-reorder: HTML5 drag API or a lightweight lib (no npm — inline).
