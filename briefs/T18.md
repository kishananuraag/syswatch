# T18 — Collector storage cascade (disk-side down-sampling)

## Problem (measured)

Collector samples at 1 s, ~6.7 KB/sample, raw JSONL on disk.
- 24 MB/h · 576 MB/day · ~210 GB/year for one machine.
- The energy cascade (1 s → 15 s → 60 s → 300 s → 1800 s, max+mean)
  exists ONLY in the in-memory `HistoryIndex`. Disk is raw forever.
- `history/` and `data/` dirs are empty.

## Goal

Apply the cascade at write time so steady-state footprint is ~52 MB
(50 MB rolling 30-day window + ~2 MB archived) instead of 210 GB/year.

## Design

1. **Rolling raw buffer (last 6 h at 1 s)** — append to
   `logs/raw/YYYY-MM-DD.jsonl` (rotates daily). Max 6 h of 1 s data
   (~24 MB). Older raw lines are compacted, not deleted abruptly.

2. **Tiered compact files** (one line per bucket, max+mean per metric):
   - `logs/tier15s/`   — 15 s buckets, kept 6 h→1 d
   - `logs/tier60s/`   — 60 s buckets, kept 1 d→7 d
   - `logs/tier300s/`  — 300 s buckets, kept 7 d→30 d
   - `logs/tier1800s/` — 1800 s buckets, kept 30 d→1 y
   - `logs/archive/`   — 1 record/day (max+mean per metric), kept forever
     (~1 KB/record ≈ 365 KB/year)

3. **Compaction pass on startup** and every hour: walk the tiers, merge
   buckets that have aged past their tier's window into the next coarser
   tier, then delete the source. Idempotent: re-running on already-compacted
   data is a no-op.

4. **Schema**: compact record = same keys as raw but values are
   `{min, max, mean, n}` for continuous metrics; counts for events.
   Keep the top-level shape so `/api/graph` and the dashboard need no
   changes — the server already aggregates; it just reads more files.

5. **Safety**: never delete a tier file until the next tier's write is
   flushed + fsync'd. On crash, worst case = one duplicate bucket, which
   the compactor dedupes by (bucket_start, tier).

6. **Config**: `storage.cascade = true` (default on). `storage.raw_hours = 6`
   (configurable). `storage.archive = true` (default on).

## Acceptance

```
cargo build --release 2>&1 | tail -3
# after running collector for 10 min:
du -sh ~/Library/Application\ Support/syswatch/logs/
ls ~/Library/Application\ Support/syswatch/logs/tier*/ 2>/dev/null | head
# compaction idempotency:
./syswatch-collector --compact --dry-run 2>&1 | tail -5
```
Supervisor: rolling raw ≤ 6 h; tier dirs populated; archive dir grows
~1 record/day; total footprint < 100 MB after a week of real use;
`/api/graph` still returns the same points (no regression).
