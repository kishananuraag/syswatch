# T19 — Power daemon in Rust (consolidate shell + C into one binary)

Supervisor-approved direction: max efficiency + scalability. The power daemon
becomes a single Rust binary `syswatch-powerd` that replaces BOTH
`syswatch_power_sampler.sh` (shell) and `smc_temp` (C helper).

## What it does (same contract, one binary)

1. Runs as root under launchd (`com.barbarian.syswatch.power`, UserName root).
2. Every 5 s (configurable via `--interval-ms`, default 5000):
   a. Spawns `powermetrics` with samplers `thermal,cpu_power,gpu_power,
      ane_power` (probe `smc` first; drop it if this build rejects it —
      same logic as the shell script, logged to powermetrics.err.log).
   b. Parses the text output into the sample schema (cpu_w, gpu_w, ane_w,
      package_w, thermal_pressure, e_cluster {freq_mhz, residency_pct},
      p_cluster, gpu_freq_mhz, gpu_residency_pct, per_cpu[], cpu_avg_c,
      gpu_avg_c, battery_c, ssd_c, temps[], fans_rpm, smc, ts, sample_ms).
   c. Reads SMC keys via IOKit FFI (port the smc_temp.c key list + probe
      logic). Port the exact C: open AppleSMC service, iterate keys,
      read 4-byte values, filter to −20…120 °C, emit `{label, key, c}`.
   d. Merges both into one JSON object.
   e. Writes atomically: serialize to `sample.json.tmp`, fsync, rename to
      `sample.json`. (No partial reads by the dashboard.)
3. Dumps the first raw powermetrics output to `powermetrics.raw.log` as
   evidence (same as today).
4. Logs sampler rejection + first-sample confirmation to
   `powermetrics.err.log`.

## Build

- New crate member or standalone binary under `src/bin/powerd.rs` (or a
  separate `powerd/` crate). Use only std + a minimal IOKit FFI (no heavy
  deps — keep the binary < 2 MB). `serde_json` for serialization is fine
  (already a dep if the collector uses it; check Cargo.toml).
- Compile: `cargo build --release --bin syswatch-powerd`.
- Install path: `/usr/local/libexec/syswatch/syswatch-powerd` (root, 755).
- Grant flow update: `grant_root_tier()` in dashboard/server.py installs
  the Rust binary instead of running clang on smc_temp.c. The grant still
  pops ONE admin prompt (same UX). Remove the smc_temp.c compile step;
  keep the plist install + bootstrap.

## Efficiency guard

- < 0.3 % CPU averaged over 60 s (powermetrics is the dominant cost;
  interval stays 5 s, do not lower it).
- RSS < 8 MB.
- No busy-wait; sleep between cycles.
