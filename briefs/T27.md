# T27 — iroh endpoint: bind, accept connections, basic echo

## Goal

Add an iroh endpoint to the net crate. The endpoint binds on startup, publishes
its NodeId, and accepts incoming connections. A basic echo protocol proves
the transport works before we layer pairing + encryption on top.

## What to build

1. `IrohEndpoint` struct in `crates/net/src/endpoint.rs`:
   - `bind(identity: &DeviceIdentity) -> Result<Self, NetError>`
   - Uses `iroh::Endpoint` with the device's secret key
   - `node_id() -> PublicKey`
   - `accept() -> impl Stream<Item = Connection>`
   - `connect(node_id: PublicKey) -> Result<Connection, NetError>`

2. A simple ALPN protocol (`syswatch/1`) for the echo test.

3. Tests: bind endpoint, get node_id, connect two endpoints (localhost).
