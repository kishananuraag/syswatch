# T25 — Rust agent: /api/sensors + /api/series + /api/consumers

## Goal

Migrate three more endpoints to the Rust agent. The Python server stays as fallback.

## Endpoints

### GET /api/sensors
Returns the sensor manifest: list of sensors with their MetricDefs.
Use syswatch-sensors-macos to probe all sensors and return the manifest as JSON.

### GET /api/series?metric=X&from=Y&to=Z&max_points=N
Returns a time series for a metric. Read from the collector's JSONL files in
~/Library/Application Support/syswatch/history/ or logs/. Return array of
{ts, value} or {ts, min, max, avg, count} if rollups available.
For now, read the latest raw JSONL and filter by time range.

### GET /api/consumers (or /api/apps)
Returns the app/process consumer list. Read from the latest collector sample
or the apps JSONL. Return array of {name, pid, cpu_pct, memory_mb, ...}.
