# T28 — Pairing protocol: code exchange → encrypted iroh connection

## Goal

Implement the pairing flow: device A generates a code, device B enters it,
they connect via iroh and establish an encrypted channel using X25519 + ChaCha20Poly1305.

## What to build

1. `crates/net/src/pairing.rs`:
   - `PairingSession`: state machine (Waiting → CodeGenerated → Connected → Paired)
   - `start_pairing(identity) -> (PairingCode, PairingHandle)`
   - `accept_pairing(code) -> Result<PairedConnection, NetError>`
   - `PairingHandle::wait_for_peer() -> Result<PairedConnection, NetError>`

2. `PairedConnection`:
   - Wraps an iroh connection + shared secret
   - `send(data: &[u8]) -> Result<(), NetError>` (encrypts + sends)
   - `recv() -> Result<Vec<u8>, NetError>` (receives + decrypts)
   - `peer_node_id() -> PublicKey`

3. Key exchange: X25519 ECDH using ring or iroh's built-in keys.
   Use iroh's PublicKey as the identity, derive shared secret via
   X25519 (ring crate is available).

4. Encryption: ChaCha20Poly1305 (chacha20poly1305 crate, check availability).
