# T23 — Port remaining sensors to sensors-macos

Port memory, disk, network, battery, and thermal sensors to the new `Sensor` trait
in `crates/sensors-macos/`. Each sensor implements `probe()` (returns MetricDefs)
and `sample()` (fills SampleBuf). Use `sysinfo` for CPU/memory/disk/network.
Use IOKit FFI for thermal (SMC keys). Use the power daemon's sample.json for
battery/power data.

## Sensors to port

1. **MemorySensor** — total, used, available, pressure, swap. Metrics: memory.total,
   memory.used, memory.available, memory.pressure, memory.swap_used.
2. **DiskSensor** — per-disk read/write bytes/sec. Metrics: disk.{name}.read_bytes_sec,
   disk.{name}.write_bytes_sec, disk.{name}.usage.
3. **NetworkSensor** — per-interface rx/tx bytes/sec. Metrics: net.{iface}.rx_bytes_sec,
   net.{iface}.tx_bytes_sec.
4. **BatterySensor** — charge %, health %, cycles, draw W, time remaining.
   Reads from sample.json (root daemon) or IORegistry. Metrics: battery.charge_pct,
   battery.health_pct, battery.cycles, battery.draw_w, battery.time_remaining_min.
5. **ThermalSensor** — SMC temps (CPU die, GPU, SSD, battery). Reads SMC keys
   via IOKit. Metrics: temp.cpu.die, temp.gpu, temp.ssd, temp.battery.

## Acceptance

```
cd crates/sensors-macos && cargo build && cargo test
```
All sensors probe and sample without panic. Each sensor's probe returns at least
one MetricDef. Each sensor's sample fills at least one value.
