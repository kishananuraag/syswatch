# T29 — Viewer: read-only metric stream over paired connection

## Goal

Implement the viewer: a paired peer that receives a read-only stream of
metrics from the device. The device sends its current snapshot every tick;
the viewer decrypts and displays it.

## What to build

1. `crates/net/src/viewer.rs`:
   - `ViewerSession`: connects to a paired device, receives metric snapshots
   - `ViewerSession::connect(paired: PairedConnection) -> Self`
   - `ViewerSession::next_snapshot() -> Result<Snapshot, NetError>` (async)
   - `Snapshot`: deserializable struct matching /api/current shape

2. `crates/net/src/stream.rs`:
   - `MetricStream`: sends snapshots from device side
   - `MetricStream::new(paired: PairedConnection, snapshot_fn: Box<dyn Fn() -> Value + Send>)`
   - `MetricStream::run()` (async, sends every tick)

3. Tests: round-trip (device sends snapshot, viewer receives it)
