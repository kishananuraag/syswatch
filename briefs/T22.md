# T22 — Focus-mode tiles + customization (the real T21)

T21 did not implement these. This brief is the actual build.

## Focus mode

When a tile is clicked:
1. The clicked tile gets `is-focused` class → expands to 2x size (span 2 cols, 2 rows).
2. All other tiles get `is-dimmed` class → opacity 0.35, pointer-events none.
3. The expanded tile shows: full chart (horizontally scrollable) + stats to the side.
   For CPU: chart + per-core list (P1-P4, E1-E4) with MHz and residency.
   For Thermal: chart + all SMC temps (CPU die, GPU, SSD, battery).
   For others: chart + key measures.
4. Click the focused tile again OR click another tile OR press Escape → unfocus.
   All tiles return to normal. Transition: 150 ms opacity/transform.

## Dynamic tiles (not static bars)

- Each tile: number (24 px, tabular) + sparkline (40 px) + delta (10 px).
- No bars filling left-to-right. The sparkline is the only visual.
- Hover: tooltip with mini chart (30 px, last 60 s) + source line. No click needed.

## Temperature tile (special)

- One tile shows ALL temps: CPU die, GPU, SSD, battery (compact list).
- Combined sparkline of CPU temp over time.
- Clicking it → focus mode (dims others, no expansion). Just highlights.

## Customization

- A "customize" toggle in ⚙ settings.
- When enabled: tiles show a drag handle. User can:
  - Reorder tiles (drag-to-reorder within the grid)
  - Show/hide tiles (checkbox per tile)
  - Settings persist in localStorage (`syswatch-tile-config`)
  - Reset to default button
- When disabled: tiles are fixed, no drag handles.
