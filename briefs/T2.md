# T2 — Measurement harness (steady-state cost of syswatch)

## Goal
`scripts/measure_collector.py` must measure syswatch's steady-state CPU and memory over time and support before/after comparison, so every optimization in this repo can be proven with numbers instead of opinions.

## Context (read these first)
- `scripts/measure_collector.py` — existing harness, extend it (do not rewrite from scratch if it already does something)
- `scripts/precise_cpu.py` — helper for CPU sampling
- `src/json.rs`, `src/main.rs` — how `syswatch --json` emits a snapshot
- `BRAIN.md` — project state

## Required behaviour
1. `python3 scripts/measure_collector.py --duration SECONDS --out PATH` runs for SECONDS (default 60), sampling every 1s, and writes a CSV with header exactly:
   `ts,elapsed_s,cpu_pct,rss_kb,json_ok,cpu_total_pct`
   - `cpu_pct` = the CPU percent of the *syswatch process being measured* (from `ps -o %cpu= -p PID`), not the machine's CPU
   - `rss_kb` = `ps -o rss=` for that PID in KB
   - `json_ok` = 1 if `syswatch --json` returned valid JSON that tick, else 0
   - `cpu_total_pct` = the machine-wide CPU percent from that JSON
2. `--compare BEFORE.csv AFTER.csv` prints a small table of deltas: mean cpu_pct, mean rss_kb, max rss_kb, p95 cpu_pct, sample counts, and the % change for each. Exit 0.
3. `--help` documents both modes and every flag.
4. Backwards compatible: any existing flags must keep working.

## Constraints
