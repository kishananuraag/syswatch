# T17A — Instrument L1: bento layout + L2 drawer + theme pass

Build the new information architecture approved from the mockup
(`cache/scratch/syswatch-instrument-mockup.html`). Replace the long stacked
sections on `#instrument` with a single-viewport bento.

## Layout (one viewport at 1920×1080, no full-page scroll on L1)

Row 0 — topbar: brand + 3 tabs (Instrument · Apps · Analytics) + ⚙ + sticky
centered range pill (1m 5m 15m 1h 6h 1d 7d 30d 1y), position:sticky top.

Row 1 — six vital chips, one row:
  CPU · Memory · GPU · Battery · Package power · Thermal
  Each chip: name (10.5 px uppercase muted), number (20 px tabular), meta
  (10.5 px), 22 px sparkline, delta line. Click chip → opens L2 drawer for
  that module.

Row 2 — 8/4 split:
  Left (span 8): wide CPU chart in a horizontally scrollable box
  (overflow-x:auto, min-width 720, custom 6 px scrollbar). Coverage line
  underneath. Drag on the chart to zoom (brush → snaps to ladder step;
  double-click resets).
  Right (span 4): P/E rings + per-core rows + Top consumers (5 rows,
  virtualised if > 30) + "click to drill through".

Row 3 — three equal tiles: Network · Disk (speeds) · Power timeline.
  Each: vital + sparkline + coverage.

## L2 drawer

Clicking any vital/chip/tile opens a right-side slide-over (transform 200 ms)
containing the FULL module: chart (scrollable) + consumers (full virtualised
list) + coverage + findings block (3–4 sentences) + records feed. Esc / click
backdrop closes. Hash stays `#instrument` (drawer is overlay, not a route).

## Theme pass ("calm instrument", single accent)

- Base `#121317`, surface `#181A1F`, line `#262A33`, fg `#E6E9EF`,
  muted `#8B93A7`, dim `#5B6273`, accent `#5EEAD4` ONLY. Remove any second
  accent colour usage except the warn state (`#F87171`) and the battery
  amber (`#F59E0B`) — and only on those two.
- Tabular figures everywhere (`font-variant-numeric: tabular-nums`).
- No box-shadows. Depth by lightness steps only.
- 150 ms opacity/transform micro-interactions only (no layout animation).
- Hover: border-color step to `#303540`, 150 ms. No lift.
- Charts: thin line (1.6 px), soft gradient fill, gridlines 1 px `#262A33`,
  axes labels 10 px dim. Coverage line 11 px dim with a bolded measured-%.
- Horizontal scrollbar 6 px, thumb `#303540`.

## Rules carried over (do not regress)

- Single global range control (the sticky pill). No per-card ranges.
- No "gap to leader". Share of total only.
- Honest gaps: spanGaps:false, no fake 0.
- `document.hidden` pauses polling (already).
- Temps from root: hero chip shows CPU/GPU die °C when `root.cpu_temp_c`
  exists, else "needs root".
