# T10 — Headless collector mode (no tty, launchd-ready)

## Why
On macOS the collector **cannot run unattended**: `service run` prints
`service management is only supported on Windows`, and every other mode calls
`terminal::enable_raw_mode()` and exits with `Failed to enter raw mode` when
stdout is not a pty. Consequences:
- T8's launchd agent cannot work — launchd never provides a tty.
- Every cost measurement so far had to be faked through `script -q /dev/null`,
  and the numbers include full-screen TUI repaints.

## Do this
1. Add a `--headless` flag (long form; no short alias needed).
   - Skips raw-mode setup entirely and never renders a frame.
   - Implies the logging behaviour of `--log` (append one JSON object per tick).
   - Honours `--interval-ms` (default 1000) and `--no-color` silently (no-op).
   - Keeps `--json` one-shot semantics untouched: `--json` still prints one
     frame and exits; `--headless` runs until signalled.
2. Reuse the existing collector loop. Do **not** duplicate the sampling code.
   The only difference between headless and live is: no raw mode, no render.
3. Signals: `SIGTERM` and `SIGINT` must flush the current log line and exit
   with status **0** within 1 s. Use a `signal_hook`-free approach if possible
   (a plain `ctrlc`-style handler or `libc::signal`); if a new crate is needed,
   say so in the report and justify it — a dependency for this is acceptable
   only if std cannot do it.
4. Startup line: print exactly one line to stderr —
   `syswatch: headless collector started (interval 1000 ms, log <path>)` —
   so launchd's log has a start marker. Nothing else on stderr unless an error.
5. Do not change the JSON schema, the log format, or any existing flag.

## Constraints
- Additive only. `--json`, live TUI, history view, and `--log` keep working exactly as now.
- No new heavyweight crates. No subprocess per sample.
- Do not touch `dashboard/`, `briefs/`, `GOAL.md`, `LEDGER.jsonl`, `tools/`, `.hermes/`.

## Acceptance commands (all must exit 0)
```bash
cargo build --release 2>&1 | tail -3

# 1. runs with NO controlling terminal (this is the whole point)
rm -rf /tmp/t10hist && mkdir -p /tmp/t10hist
setsid ./target/release/syswatch --headless --interval-ms 1000 --log-dir /tmp/t10hist > /tmp/t10.out 2> /tmp/t10.err < /dev/null &
PID=$!
sleep 6
kill -0 $PID || { echo "DIED"; cat /tmp/t10.err; exit 1; }
echo "ALIVE pid=$PID"
grep -q "headless collector started" /tmp/t10.err && echo START_MARKER_OK

# 2. it is actually logging
F=$(ls /tmp/t10hist/*.jsonl 2>/dev/null | head -1)
[ -n "$F" ] || { echo "NO_LOG_FILE"; exit 1; }
LINES=$(wc -l < "$F")
echo "LOG $F lines=$LINES"
[ "$LINES" -ge 3 ] || { echo "TOO_FEW_LINES"; exit 1; }
python3 -c "import json,sys;[json.loads(l) for l in open('$F') if l.strip()];print('LOG_JSON_OK')"

# 3. clean shutdown, status 0, fast
START=$(python3 -c "import time;print(time.time())")
kill -TERM $PID
wait $PID; RC=$?
END=$(python3 -c "import time;print(time.time())")
echo "EXIT_RC=$RC  shutdown_s=$(python3 -c "print(round($END-$START,2))")"
[ "$RC" -eq 0 ] || { echo "BAD_EXIT"; exit 1; }

# 4. nothing left behind
sleep 1
pgrep -f "syswatch --headless" && { echo "LEAK"; exit 1; } || echo NO_LEAK

# 5. honest steady-state cost, NO tty and NO render in the way
setsid ./target/release/syswatch --headless --interval-ms 1000 --log-dir /tmp/t10hist > /dev/null 2>&1 < /dev/null &
P2=$!
sleep 4
T0=$(ps -o time= -p $P2 | tr -d ' '); R0=$(ps -o rss= -p $P2 | tr -d ' ')
sleep 30
T1=$(ps -o time= -p $P2 | tr -d ' '); R1=$(ps -o rss= -p $P2 | tr -d ' ')
kill -TERM $P2 2>/dev/null
python3 - "$T0" "$T1" "$R0" "$R1" <<'PY'
import sys
def secs(t):
    total = 0.0
    for v in (t or "0").strip().split(':'):
        total = total * 60 + float(v)
    return total
t0, t1, r0, r1 = sys.argv[1:5]
d = secs(t1) - secs(t0)
print(f'headless cpu {100*d/30:.2f}% over 30s, rss {int(r0)/1024:.1f}->{int(r1)/1024:.1f} MB')
assert 100*d/30 < 1.5, 'headless collector above 1.5% CPU'
print('COST_OK')
PY

# 6. nothing regressed
./target/release/syswatch --json > /tmp/t10.json && python3 -m json.tool /tmp/t10.json > /dev/null && echo JSON_STILL_OK
```
