# T4 — Make the 8123 dashboard server durable, and give the cockpit a host

## Goal
`dashboard/server.py` works but is not running, so `syswatch-tray` polls a dead endpoint and there is no stable place for live agent work to appear. Make it start reliably, stay single-instance, expose health, and serve an SSE stream of agent events.

## Context
- `dashboard/server.py` (883 lines, `ThreadingHTTPServer`, `SYSWATCH_PORT` default 8123). Already serves `/api/current`; verified alive on macOS with `SYSWATCH_DASHBOARD_READY on port 8123`.
- `syswatch-tray` polls `http://127.0.0.1:8123/api/current`.
- `.hermes/run/events.jsonl` is the agent event log (may not exist yet — create dirs on demand, never crash).
- `LEDGER.jsonl` at repo root holds task attempts.

## Required behaviour
1. `python3 dashboard/server.py` starts, prints the READY line, and keeps serving. Second instance must **not** double-bind: detect the existing server and exit with a clear message and non-zero code (or exit 0 with "already running" — pick one, document it in `--help`).
2. `GET /api/health` → 200 JSON: `{"ok":true,"pid":<int>,"uptime_s":<float>,"port":8123,"events_age_s":<float|null>}`
3. `GET /api/current` keeps working exactly as now (do not break existing field names — the tray depends on them).
4. `GET /api/agent-stream` → SSE (`text/event-stream`), sending one `data: {json}` line per new line appended to `.hermes/run/events.jsonl`, plus an initial `data: {"kind":"hello"}` so clients connect even when the log is empty. Must not block the rest of the server; must survive the file being rotated or deleted.
5. `GET /api/agent-events?limit=50` → 200 JSON array of the last N events (tail read, do not load the whole file).
6. Clean shutdown on SIGTERM: port released, no orphan child processes.
7. `--port`, `--host` flags override defaults; `--help` documents everything.

## Constraints
- **Do NOT run cargo, do not touch `src/`, `Cargo.toml`, `scripts/`, `briefs/`, `GOAL.md`, `LEDGER.jsonl`.**
- Python stdlib only (psutil is already used by this file and is fine).
- No sudo, no LaunchAgent / launchctl changes (that is T8, intentionally out of scope).
- Bind `127.0.0.1` by default — never expose to the network.
- Keep the existing sampling/psutil logic intact; this task is about lifecycle and endpoints, not new metrics.
