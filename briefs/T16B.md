## 1. SMC temperature reader (the iStat-grade piece)

Temperatures on Apple Silicon come from SMC keys, read through the AppleSMC
IOKit user client — the same mechanism iStat Menus and the open-source
`smctemp` (github.com/narugit/smctemp, MIT) use. We ALREADY run a root
daemon; use it.

- Vendor a small C helper `packaging/launchd/smc_temp.c` (port the smctemp
  key list: on Apple Silicon temperature keys live in namespaces like
  `Tp`, `Tm` etc. — probe, do not assume names): opens AppleSMC, iterates
  the key list, reads 4-byte values, emits JSON of `{key, label, c}` for
  every key that yields a sane temperature (−20…120 °C). Labels mapped via
  a small table (CPU/GPU/battery/palm rest/SSD); unmapped keys keep
  `Sensor <key>` — honest naming, same policy as iStat parity.
- `syswatch_power_sampler.sh` calls the compiled helper each cycle and merges
  its output into `sample.json` as `temps: [{label, key, c}]`. Compile at
  grant time with `cc -O2 -framework IOKit -framework CoreFoundation` into
  `/usr/local/libexec/syswatch/smc_temp`; if compile or probe fails, the
  sample simply omits `temps` and the UI keeps the honest `unavailable`.
- The dashboard reads `temps` through the registry (T16A's thermal slot).
