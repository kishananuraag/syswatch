# T24 — Rust agent: axum HTTP server skeleton + /api/health + /api/current

## Goal

Create `crates/agent/` — a Rust binary that serves the same HTTP API as
`dashboard/server.py` on port 8123 (or a test port). Start with two endpoints:
`/api/health` and `/api/current`. The Python server stays as fallback.

## Architecture

- HTTP framework: `axum` (tokio-based, ergonomic, good SSE support).
- Static files: serve `dashboard/static/` via `tower-http` ServeDir.
- Data: read from the same sources as Python (collector JSONL, root sample.json).
- Port: configurable via `--port` (default 8123). For testing use 8199 to avoid
  conflicting with the live Python server on 8123.

## Endpoints to migrate

### GET /api/health
Returns: `{"ok": true, "pid": N, "uptime_s": N, "port": N}`

### GET /api/current
Returns the current system snapshot: CPU, memory, GPU, battery, network, disk,
package power, thermal pressure, load averages. Read from:
- Collector's in-memory state (or latest JSONL line)
- Root sample.json (power/temps)

## Dependencies

- axum, tokio, tower, tower-http (serve-dir, cors)
- serde, serde_json
- syswatch-core, syswatch-store, syswatch-sensors-macos

## Acceptance

```
cd crates/agent && cargo build 2>&1 | tail -3
# Start on test port
./target/debug/syswatch-agent --port 8199 &
sleep 3
curl -s http://127.0.0.1:8199/api/health
curl -s http://127.0.0.1:8199/api/current | head -c 500
# Compare /api/health shape with Python's
curl -s http://127.0.0.1:8123/api/health
```

Supervisor verifies: both return 200, JSON shapes match for health, agent responds
