# T9 — Cockpit: open syswatch and watch the agents work

## Goal
The app/dashboard shows live agent work from `.hermes/run/events.jsonl`, so supervising the fleet means glancing at syswatch instead of watching a chat. Read-only in this slice — no approve/reject buttons yet.

## Data contract (already implemented by T4b — reuse, do not change)
`GET /api/agent-events?limit=N` → JSON array of the last N events.
`GET /api/agent-stream` → SSE, one `data: {...}` per new line, `{"kind":"hello"}` on connect.
Event shape: `{"ts","job","kind":"dispatch|stdout|verify|retry|pass|fail|park|deferred|sleep|wake","model","attempt","exit","duration_s","text"}` — `text` ≤ 500 chars.

## Panes (build these, in this order — each must be usable alone)
1. **NOW** — the currently running task: job id, model, attempt, elapsed, the last `stdout` line. Empty state: `idle — queue empty` (never a spinner that lies).
2. **QUEUE** — chips for every task from `.hermes/queue.json`: `queued | running | verifying | done | failed | blocked | needs_review` with counts. Read `.hermes/queue.json` through the server (new read-only endpoint `GET /api/queue`), never from the browser's filesystem.
3. **LEDGER** — last 50 rows from `LEDGER.jsonl`, one line each: ts · job · attempt · exit · acceptance · duration. Failures stay visible; do not filter them out.
4. **GOAL** — the first paragraph of `GOAL.md`, static, plus `n/m acceptance passing` derived from the ledger's latest verdict per task.

## Rules
- Read-only. No buttons that mutate queue, ledger or files.
- The cockpit must stay correct when the events file is missing, empty, rotated or being appended to mid-line (tolerate a truncated last line).
- Failure must look like failure: red is reserved for `fail`/`park`, never decoration.
- No CDN, no framework, no build step. Same typographic rules as T5.

## Constraints
- Touch `dashboard/` only (server routes + static assets). Do not touch `src/`, `briefs/`, `GOAL.md`, `LEDGER.jsonl`, `tools/`, `scripts/`.
- Do not break `/api/health`, `/api/current`, `/api/agent-events`, `/api/agent-stream`, `/api/graph`.
- Bind `127.0.0.1`. Python stdlib for the server.
