# T30 — Stateless relay: ciphertext-only forwarding between paired devices

## Goal

Implement the relay server: a stateless process that forwards encrypted
messages between paired devices. The relay never sees plaintext — it only
routes based on node IDs and pairing tokens.

## What to build

1. `crates/relay/` — new crate:
   - `RelayServer`: binds on a port, accepts iroh connections
   - Routes messages between peers by node ID
   - No state beyond active connections (stateless)
   - No decryption, no message inspection

2. `crates/net/src/relay_client.rs`:
   - `RelayClient`: connects to relay, registers node ID
   - `RelayClient::forward_to(peer: PublicKey, data: &[u8])`
   - `RelayClient::recv() -> Option<(PublicKey, Vec<u8>)>`

3. Protocol: relay assigns each connection a node ID. When device A sends
   a message tagged with device B's node ID, the relay forwards it to B.
   The relay only sees ciphertext + routing header.
